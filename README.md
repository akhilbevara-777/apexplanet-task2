# ApexPlanet Portfolio

## Overview
The ApexPlanet Portfolio is a professional and interactive web portfolio designed to showcase skills, projects, and contact information in a visually appealing manner. The portfolio utilizes modern web technologies including HTML5, CSS3, JavaScript, and Bootstrap 5 to create a responsive and user-friendly experience.

## Features
- Responsive Bootstrap Navbar
- Hero Section with engaging visuals
- About Section detailing personal information
- Skills Section highlighting technical proficiencies
- Projects Section showcasing work samples
- Contact Section for inquiries
- Footer with additional links and information

## Design
- Dark modern UI with a blue accent color
- Mobile responsive design for optimal viewing on all devices
- Smooth scrolling for navigation links
- Attractive animations to enhance user experience
- Professional layout suitable for recruiters and potential employers

## Setup Instructions
1. Clone the repository to your local machine.
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory.
   ```
   cd apexplanet-portfolio
   ```
3. Open `index.html` in your preferred web browser to view the portfolio.
